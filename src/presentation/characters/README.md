# Nhân vật

| Muốn sửa | Mở |
| --- | --- |
| Thân nam gốc | `body/male/male_body.gd` |
| Thân nữ (chưa làm) | `body/female/` |
| Khuôn mặt | `body/face/face_shapes.gd` |
| Danh sách ô và món đồ | `equipment/equipment_catalog.gd` |
| Tóc, áo, quần, giày, áo choàng | `equipment/clothing/` |
| Hình dáng kiếm, trượng | `equipment/weapons/` |
| Hiệu ứng chiêu | `effects/skill_effects.gd` |
| Chạy, đứng, dừng | `moves/common/` |
| Tư thế cầm và chiêu theo class, hệ | `moves/<class>/<hệ>/` |
| Dựng scene và animation | `rig/tools/build_rig.gd` |
| Ghép nhân vật, xương, di chuyển | `rig/jointed_rig.gd` |
| Tay thứ hai bám vũ khí | `rig/two_hand_grip.gd` |
| Áo choàng, vạt áo lắc theo | `rig/spring_motion.gd` |

Mỗi món đồ trả về hình cho từng xương và danh sách phần thân nó che. Đồ không đổi va chạm hay sức mạnh.
